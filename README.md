![Holberton](https://img.shields.io/badge/Holberton-School-red?style=flat-square) ![Shell](https://img.shields.io/badge/Shell-Bash-4EAA25?style=flat-square&logo=gnubash) ![DevOps](https://img.shields.io/badge/DevOps-Automation-orange?style=flat-square)

## Description

This repository covers **System Engineering and DevOps** — the practices and tools that bridge software development and IT operations. Topics include web infrastructure, server configuration, automation with Bash and Puppet, monitoring, and CI/CD pipelines.

## Learning Objectives

- Understand web infrastructure design (single server to distributed)
- Automate system configuration with Bash and Puppet
- Configure and secure Nginx web servers
- Implement load balancing with HAProxy
- Set up HTTPS with SSL/TLS certificates
- Monitor systems with Datadog
